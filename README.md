# Convertir-Exceltxt

En una aplicación de escritorio que te permite convertir un archivo de excel
a un archivo de texto plano con sentencias sql(insert o delete) para cada una de las filas.

## Requisitos para ejecutar

- Java 17 o mayor (JRE/JDK)

## Descargar jar

Ir a la seccion [Releases en GitHub](https://github.com/yamendez/Convertir-Exceltxt/releases),  luego descargar el archivo ConvertirTablatxt.jar
